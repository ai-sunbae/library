### 수치로 확인된 패턴

1. **대사와 자막이 없다.** 상위 10개 중 7개는 음성 인식으로도 자막 추출로도 텍스트가 나오지 않았다. 나머지 3개도 배경음악 가사뿐이다. 그래서 댓글이 영어·스페인어·아랍어·중국어·힌디어로 달린다. 말이 없으니 국경 없이 퍼진다.
2. **짧다.** 상위권 중앙값은 약 15초다. 4초, 7초짜리도 100만 회를 넘겼다. 37초는 예외에 가깝다.
3. **캡션은 1~5단어 + 이모지.** "🐹💢", "와아-😋". 설명은 하지 않고 영상이 다 말한다.
4. **주제는 일상 공감이다.** 짜증, 늦잠, 먹을 것 뺏기기, 나눠 먹기, 비 오는 날. 누구나 겪어본 3초짜리 감정 하나를 다룬다.
5. **공유는 친구 태그로 일어난다.** 상위 릴스 댓글 대부분이 "@친구 이거 너", "EVERYTIMEE", "100% me"다. "이거 너잖아" 하고 보내고 싶은 순간이 알고리즘을 움직인다.
6. **사운드**: 1위는 국내 밈 사운드("짜증날 때 짜장면"), 2위는 쇼팽 녹턴처럼 장면과 반대되는 음악이다. 오리지널 효과음 위주인 릴스도 상위권에 많다.
7. **업로드**: 2~3일에 1개, 거의 항상 18:00 KST(09:00 UTC).
8. **협찬·홍보 게시물은 도달이 1/10 이하로 떨어진다.** 수익화는 이모티콘, 굿즈, 포토부스 콜라보로 하고 피드는 공감 릴스로 채운다.

### 그대로 따라 하면 안 되는 것

- 이 계정의 힘은 손그림 프레임 애니메이션(표정과 몸짓이 쫀득하게 움직임)에서 나온다. 기획만 따라 하고 움직임 품질이 낮으면 같은 결과는 나오지 않는다.
- 동물 3마리, 오리·햄스터·토끼 조합, 이름 짓는 방식은 피한다. 겹치면 "두햄빠 짝퉁"으로 읽힌다.

## 2단계. 캐릭터 기획

### 메인: 두부 (TOFU)

| 항목 | 설정 |
|---|---|
| 정체 | 말랑한 연두부 한 모. 동물이 아니라서 레퍼런스와 겹치지 않는다 |
| 실루엣 | 둥근 모서리 정사각형. 점 눈, 볼터치, 짧은 다리. 작게 줄여도 알아볼 수 있다 |
| 성격 | 게으르고 겁 많고 금방 녹는다(물리적으로) |
| 시그니처 동작 | **녹기**: 행복하거나 안심하면 바닥에 납작하게 퍼진다. 매 화 엔딩으로 반복해 "두부 녹는 거 보러 오는" 계정을 만든다 |
| 컬러 | 두부 #FFFDF5 / 라인 #3A2E2A / 볼터치 #FFB6B6 / 배경 파스텔 피치 |

### 서브 (EP05 이후 등장 추천)

- **고추장**: 빨갛고 성질 급함. 두부를 재촉하는 역할로 갈등을 만든다
- **김**: 얇고 펄럭이는 소심이. 바람만 불어도 날아간다

조합 원칙: 성격이 정반대인 셋을 묶는다(느긋함 / 급함 / 소심함). 한 장면에 둘만 나와도 갈등이 생긴다.
